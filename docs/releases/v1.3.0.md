This release rebrands the fictional company as _Bon Voyage_ and introduces a more
reliable, transparent RAG architecture for the travel assistant.

## Highlights

- Rebranded the fictional travel company as _Bon Voyage_, with **Petit Guide** as its
  travel assistant identity.
- Renamed the Docker application service from `agent` to `app` across Compose, Makefile,
  images, documentation, and deployment configuration.
- Rebuilt the agent workflow with LangGraph.
- Added explicit planning, retrieval, evidence evaluation, answer generation, and
  refusal states.
- Added bounded retries and citation validation to reduce unsupported answers.
- Separated conversation management from turn-level agent reasoning.
- Persisted provider-neutral chat messages, sources, flow state, and execution metadata.
- Improved feedback tracking across the API, CLI, and Gradio interface.
- Fixed Gradio suggested questions so users see readable labels instead of internal IDs.
- Corrected identity-section navigation and follow-up suggestions.
- Centralized repeated chat text and removed unused code.
- Updated the README, roadmap, architecture documentation, and operational guides.
