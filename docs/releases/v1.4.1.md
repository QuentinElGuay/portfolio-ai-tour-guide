## Overview

This release makes _Bon Voyage_ easier to try before configuring an LLM or ingesting
guides. Demo mode now remains useful without a knowledge base, while live LLM
deployments clearly explain when source material has not yet been ingested. The Gradio
chat now starts an independent, reliable conversation for every browser session.

## Highlights

- Demo mode answers its prepared questions without retrieved documents and suggests a
  supported question for unsupported free-text requests.
- The chat labels the assistant as **Petit Guide (demo mode)** instead of showing a
  limitation banner in the welcome message.
- Each Gradio client starts its own backend conversation through `/chat/start`; the
  backend welcome message is retained as the first normal chat message.
- User messages appear immediately while Petit Guide is preparing a response, preserving
  the conversation order.
- The lightweight chat process no longer needs embedding configuration simply to start.
- HTTP-backed demo chats add a configurable randomized 2–3 second response delay to make
  prepared answers feel less instantaneous.
- Chat persistence now uses the provider-neutral `request_id` field, with an automatic
  migration from the older `rag_request_id` column.
- Live LLM deployments start with an empty knowledge base and explain how to ingest
  guides before source-grounded travel answers are available.
- The README and tutorial now document a progressive setup: demo mode, a live LLM with
  an empty knowledge base, then a source-grounded travel assistant.
- The environment template no longer includes a placeholder LLM API key.
- The chat interface no longer exposes unused Gradio API and settings links.
- Docker GitHub Actions have been updated to their current major versions.
