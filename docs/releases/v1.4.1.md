## Overview

This release makes _Bon Voyage_ easier to try before configuring an LLM or ingesting
guides. Demo mode now remains useful without a knowledge base, while live LLM
deployments clearly explain when source material has not yet been ingested.

## Highlights

- Demo mode answers its prepared questions without retrieved documents and suggests a
  supported question for unsupported free-text requests.
- The assistant presents a consistent demo-mode notice in the chat interface and API.
- Live LLM deployments start with an empty knowledge base and explain how to ingest
  guides before source-grounded travel answers are available.
- The README and tutorial now document a progressive setup: demo mode, a live LLM with
  an empty knowledge base, then a source-grounded travel assistant.
- The environment template no longer includes a placeholder LLM API key.
- Docker GitHub Actions have been updated to their current major versions.
