## Highlights

- The app now starts with an empty knowledge base.

- Document ingestion is optional for the guided demo.

- Travel questions without available sources receive a clear response instead of causing
  startup failure.

- `make app` now initializes the database automatically.

- The README quick start now requires only:

  ```bash
  cp .env.template .env
  make app
  ```

- Updated the roadmap and documentation to distinguish demo mode from the full RAG
  workflow.

- Fixed the destination catalog test to match the current chat response.

## Full RAG usage

To enable source-grounded travel answers, configure an LLM API key and ingest the
document corpus. See the [project tutorial](../README.md) for the complete setup.
