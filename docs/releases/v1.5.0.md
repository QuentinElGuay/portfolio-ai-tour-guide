## Overview

This release unifies retrieval across the CLI, chat API, deterministic search
experience, and LLM agent. It clarifies the boundaries between travel-agent behavior,
LLM provider integration, deterministic answers, and retrieval-augmented generation
while preserving the existing chat API.

## Highlights

- Added a shared `TravelTurnResult` contract for free-text travel-agent responses.
- Added `DeterministicTravelAgent` for the prepared Brittany demo dataset and
  `LLMTravelAgent` for source-grounded live providers.
- Added a shared retrieval tool that supports vector, full-text, and hybrid search for
  both deterministic and LLM-backed execution.
- Added retrieval confidence classification and low-confidence handling: LLM answers
  refuse unsupported travel questions, while deterministic search returns the retrieved
  evidence directly.
- Added explicit product configuration for demo, retrieval, RAG, conversational, and
  automatic fallback modes.
- Enabled LLM and retrieval capabilities by default, while retaining environment flags
  for users who want to select a simpler execution mode.
- The outer conversation graph now consumes travel-turn results instead of requiring
  every answer to be represented as a `RAGResult`.
- Demo turns no longer retrieve documents, validate citations, or persist RAG results.
- Live OpenAI and Gemini turns continue to use RAG and retain their source, trace, and
  persistence behavior.
- Moved provider clients, settings, retries, and rate limiting into `app.llm`.
- Moved RAG infrastructure into `app.services.rag` and the demo dataset/service into
  `app.services.demo`.
- Removed the unused competing travel-agent graph and updated smoke tests to reflect
  deterministic demo answers without sources.
- Updated the CLI, HTTP API, chat integration, Docker configuration, tests, diagrams,
  and README documentation for the new architecture.
