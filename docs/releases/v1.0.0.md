This release completes the Baguette Voyages project as a reproducible, containerized
regional travel-guide RAG demonstration. It expands the service beyond Brittany, adds
Airflow ingestion orchestration, provides a no-cost demo backend, and documents the
complete workflow from ingestion to evaluation and monitoring.

### Highlights

- Added Airflow-orchestrated document ingestion through the `ingest_documents` DAG.
- Expanded the indexed content from Brittany-only material to regional travel guides.
- Added a no-cost `baguette-llm` demo provider using the `mini-croissant-1.0` model.
- Made the demo the default configuration in `.env.template`; it requires no API key.
- Added friendly fallback answers for questions outside the demo’s prepared Brittany
  coverage, including a suggested supported question.
- Kept OpenAI as the supported live LLM provider and documented `gpt-4.1-mini` as the
  recommended model.
- Improved grounded-answer handling, destination catalog retrieval, source validation,
  and fixture-backed RAG testing.
- Added deterministic smoke tests using an isolated schema and a locally generated PDF.
- Added automatic first-use Metabase fixture restoration and dashboard initialization.
- Added deterministic synthetic RAG traffic for populating Quality and Costs dashboards
  without paid LLM calls.
- Improved agent startup diagnostics for empty knowledge bases and reduced health-check
  wait time.
- Prevented concurrent ingestion failures when creating embedding-model records.
- Renamed database Make commands to the `db-*` convention and sorted the Makefile
  commands and recipes alphabetically.
- Added a complete Make command reference, an end-to-end tutorial, and public Airflow,
  chat, feedback, and dashboard screenshots.
- Added CI checks for Airflow Compose configuration and DAG imports.
- Optimized CI so full Airflow startup runs after merges to `main` and only for
  Airflow-relevant pull requests.
- Added release-tagged container image publishing to GitHub Container Registry.

### Quick start

```bash
cp .env.template .env
make db-init
make ingest
make app
```

The default configuration starts the no-cost Brittany demo. For live generation, replace
the LLM settings in `.env` with an OpenAI API key and `gpt-4.1-mini`.

### Upgrade notes

Database-related Make commands now use the `db-*` naming convention: `make init-db` →
`make db-init` `make reset-db` → `make db-reset` `make reset-schema` →
`make db-reset-schema` `make dashboard` now initializes and restores the bundled
Metabase fixture automatically on first use.

### Validation

The release includes unit tests, deterministic fixture-backed smoke tests, type checks,
formatting and Markdown checks, Docker Compose validation, and Airflow DAG import
validation.

Further work includes ingestion and retrieval hardening, controlled prompt/model
comparisons, optional reranking and query rewriting, and future cloud deployment.
