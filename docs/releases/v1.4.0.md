## Highlights

- Added Google Gemini as a supported live LLM provider alongside OpenAI (ChatGPT).
- Added structured Gemini responses with validated citations and emotion metadata.
- Added Gemini search-query tool calling for the bounded agent workflow.
- Added provider selection through `AGENT_LLM_PROVIDER=gemini`.
- Recommended `gemini-3.5-flash-lite` (free-tier) as the low-cost Gemini model for this
  project.
- Updated the dependency lockfile, configuration template, tests, and documentation.

## Configuration

```dotenv
AGENT_LLM_PROVIDER=gemini
AGENT_LLM_API_KEY=your-gemini-api-key
AGENT_LLM_MODEL=gemini-3.5-flash-lite
```

Google lists a free tier and low paid-tier rates for Gemini 2.5 Flash-Lite. See the
[Gemini model page](https://ai.google.dev/gemini-api/docs/models/gemini-3.5-flash-lite)
and [current pricing](https://ai.google.dev/gemini-api/docs/pricing) for details.
