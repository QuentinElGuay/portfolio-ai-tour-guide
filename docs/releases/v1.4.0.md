## Overview

This release adds Google Gemini alongside OpenAI for structured, source-grounded answers
with bounded search-tool usage. It also improves Petit Guide’s identity and personality,
answers configured questions directly, strengthens provider reliability, and updates the
supporting configuration, tests, and docs.

## Highlights

- Added Google Gemini as a live LLM provider alongside OpenAI (ChatGPT), with provider
  selection through `AGENT_LLM_PROVIDER=gemini`.
- Added structured Gemini responses with validated citations, emotion metadata, nullable
  output fields, and bounded search-query tool calling.
- Added a consistent Petit Guide personality across conversational and retrieval
  prompts, including shared French-expression guidance for the chat UI.
- Added explicit progressive and inclusive values, scoped humor guidance, and clearer
  separation between Petit Guide’s identity and personality.
- Made configured identity and destination-catalog questions answer directly from
  application data without an LLM call; similar free-text meta questions receive the
  configured identity context.
- Exposed the active LLM provider and model in chat responses and the interface.
- Added transient retries with exponential backoff, safer response handling, and
  user-friendly errors for unavailable chat services.
- Suppressed a narrowly scoped third-party Google Gen AI deprecation warning in pytest.
- Recommended `gemini-3.5-flash-lite` (free-tier) as the low-cost Gemini model for this
  project.
- Expanded automated coverage and updated the dependency lockfile, configuration
  template, and documentation.

## Configuration

```dotenv
AGENT_LLM_PROVIDER=gemini
AGENT_LLM_API_KEY=your-gemini-api-key
AGENT_LLM_MODEL=gemini-3.5-flash-lite
```

Google lists a free tier and low paid-tier rates for Gemini 3.5 Flash-Lite. See the
[Gemini model page](https://ai.google.dev/gemini-api/docs/models/gemini-3.5-flash-lite)
and [current pricing](https://ai.google.dev/gemini-api/docs/pricing) for details.
