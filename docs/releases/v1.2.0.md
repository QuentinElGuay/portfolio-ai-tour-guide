This release improves the built-in demo backend and makes the demo experience clearer
and more robust.

### Highlights

- Added a dedicated fixture dataset with 70 answerable tourism questions.
- Excluded relocation, cost-of-living, and real-estate questions from the demo.
- Added tolerant question matching with four response levels:
  - Exact questions return exact answers.
  - Close questions return the matching prepared answer.
  - Somewhat similar questions receive a “Did you mean…?” suggestion.
  - Unrelated questions receive a random supported-question suggestion.
- Added configurable matching thresholds through agent settings.
- Added randomized welcome suggestions based on answerable tourism questions.
- Updated the demo welcome message to clarify its limited Brittany scope.
- Moved the demo fixture outside the evaluation directory.
- Kept evaluation data and code out of runtime containers.
- Fixed the chat application startup issue caused by importing database schema
  dependencies.
- Ensured LLM instructions are sent using the proper system-message role.

### Validation

- 37 focused agent tests passed.
- Ruff checks passed.
- Markdown formatting checks passed.
- Runtime chat import verified without embedding configuration.
