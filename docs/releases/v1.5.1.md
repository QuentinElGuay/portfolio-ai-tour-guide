## Overview

This patch release improves the reliability of the evaluation workflow and refreshes the
project documentation. It fixes startup errors in the RAG evaluator, keeps older corpus
exports loadable after the destination field became required, and adds regression
coverage for both issues.

## Highlights

- Fixed the RAG evaluation runner and judge factory importing `LLMProvider` from its
  current settings module.
- Added a regression test that verifies the RAG evaluation entry point remains
  importable.
- Updated corpus exports to preserve document destinations.
- Made corpus restore backward-compatible with older `documents.jsonl` files by falling
  back to the document title when `destination` is absent.
- Added corpus export and restore regression tests for the destination field.
- Reorganized the main README around Overview, Quickstart, and Workflows and operations.
- Added clearer project structure, dashboard instructions, and default development
  Metabase credentials to the README.
- Updated the README's Capstone success criteria placement and internal navigation.

- Corpus unit tests pass.
- Ruff, Markdown formatting, and diff checks pass.
